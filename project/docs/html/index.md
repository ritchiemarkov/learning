# HTML: diamo struttura alla pagina

**HTML** significa *HyperText Markup Language*: è un linguaggio di markup. Usa elementi per descrivere il significato del contenuto: un titolo, un paragrafo, un collegamento, un'immagine.

Un browser legge quel documento e costruisce una rappresentazione della pagina chiamata **DOM**. Più avanti JavaScript ci permetterà di modificarla.

## Tre ruoli diversi

| Tecnologia | Ruolo | Esempio |
| --- | --- | --- |
| HTML | Contenuto e significato | «Questo è il titolo principale» |
| CSS | Presentazione | «Il titolo è verde» |
| JavaScript | Comportamento | «Al clic aggiungi un elemento» |

Per adesso concentriamoci su HTML. Una pagina senza CSS ha già una struttura e si può usare.
