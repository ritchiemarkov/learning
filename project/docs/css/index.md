# CSS: la prossima tappa

Le lezioni CSS arriveranno dopo aver completato il [progetto HTML](/html/progetto). Useremo la stessa pagina personale, così potrai osservare che cosa aggiunge ogni regola.

## Cosa impareremo

1. Collegare un foglio di stile e scrivere selettori.
2. Capire cascata, ereditarietà e specificità.
3. Usare colori, caratteri, spazi e il box model.
4. Organizzare il layout con Flexbox e Grid.
5. Adattare la pagina agli schermi piccoli.
6. Curare contrasto e indicatori di focus.

**Progetto previsto:** rendere la pagina personale leggibile e responsive.

Per adesso, [torna alle lezioni HTML](/html/) e completa gli esercizi.
