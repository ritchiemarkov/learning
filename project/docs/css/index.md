# CSS: dalla prima regola ai layout avanzati

**35 lezioni in italiano: 15 basi e 20 approfondimenti**, con obiettivi, esempi, esercizi e soluzioni. Riprendiamo il progetto HTML e impariamo a renderlo leggibile, adattabile e utilizzabile.

La ricerca confronta [Google Learn CSS](https://web.dev/learn/css), MDN, le specifiche W3C e i criteri WAI. Nella [mappa di copertura](/css/copertura) trovi il confronto dei 37 moduli didattici Google e gli argomenti aggiuntivi, senza confondere completezza del percorso con ogni proprietà esistente.

## Quando passare a JavaScript

Completa il progetto delle basi: devi saper spiegare cascata e box model, ottenere un layout che cresce con il testo e mantenere il focus visibile. Poi inizia [JavaScript](/javascript/). Gli approfondimenti CSS accompagnano i progetti successivi; non è necessario padroneggiare ogni effetto prima di aggiungere comportamento.
