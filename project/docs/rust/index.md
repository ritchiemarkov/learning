# Rust: dopo le basi del web

Passeremo a Rust dopo aver fatto pratica con JavaScript. Le idee di variabili, funzioni e condizioni ci saranno familiari; esploreremo un sistema di tipi e un modello di gestione della memoria diversi.

## Cosa impareremo

1. Preparare Rust e usare Cargo.
2. Variabili, tipi, funzioni e controllo del flusso.
3. Ownership e borrowing con esempi piccoli.
4. Struct, enum e pattern matching.
5. Gestire assenza ed errori con `Option` e `Result`.
6. Organizzare moduli e scrivere test.

**Progetto previsto:** una lista di attività da terminale. Riprenderemo il problema affrontato in JavaScript, confrontando i due approcci.

Le lezioni Rust sono ancora da scrivere. Il primo passo rimane [la tua prima pagina HTML](/html/prima-pagina).
