# Frontend: dalle basi ai componenti

La base frontend è **HTML, CSS e JavaScript**, con accessibilità, responsive design e strumenti del browser. TypeScript aggiunge il controllo dei tipi. Un framework diventa utile dopo aver fatto pratica con questi elementi.

Questa tappa è prevista dopo la [prima applicazione completa](/fullstack/): saprai già quali dati e comportamenti deve gestire l'interfaccia. Le lezioni del framework sono ancora da scrivere.

## Un solo framework alla volta

Sceglieremo **React oppure Vue** quando arriveremo qui, in base ai tuoi interessi e al progetto. Per la prima base basta studiarne uno: la scelta non deve bloccare lo studio di HTML, CSS e JavaScript.

VitePress usa Vue per il sito delle lezioni, ma questo non ci obbliga a scegliere Vue per gli esercizi.

## Cosa impareremo

1. Componenti e responsabilità di ciascun componente.
2. Dati in ingresso, eventi e stato dell'interfaccia.
3. Rendering di liste e gestione dei form.
4. Caricamento di dati dalla API e stati di attesa, errore e successo.
5. Routing quando l'applicazione ha più schermate.
6. Riutilizzo della logica e test dei comportamenti importanti.

## Progetto previsto

Riorganizzeremo la lista di attività esistente in componenti. API e database rimarranno il punto di riferimento: confronteremo il modo di gestire l'interfaccia con quello usato in JavaScript senza framework.

Un framework full stack, come Next.js o Nuxt, potrà essere un approfondimento successivo. Prima capiremo che cosa fanno browser, server e database.
